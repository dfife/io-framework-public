# External Data Sources

Paper 27 v2.0 is a structural theorem bundle. It does not redistribute
external observational datasets.

The bundle uses only standard constants and theorem inputs already cited by
the manuscript:

- `gamma_BI = 0.2375`, imported as the Barbero-Immirzi parameter used by the
  IO framework.
- Hawking boundary temperature structure for a Schwarzschild horizon, cited
  through Hawking radiation and standard quantum field theory on curved
  spacetime.
- Standard Hodge theory on `S^3`, compact `SU(2)` representation theory,
  Schur's lemma, CCR/KMS uniqueness, and passivity/backreaction constraints,
  as cited in the manuscript and support memos.
- `R4_FIRAS = 1.0031014644`, imported from Paper 17 v1.5 as the
  FIRAS-fixed optical readout normalization. Paper 27 v2.0 does not use R4 to
  claim an independent CMB-temperature prediction.

No DESI, Planck likelihood, FIRAS data file, CLASS output table, JWST product,
or nuclear data table is bundled here.
