# Paper 21 v1.7 Reproducibility Bundle

Classification: `verified / public-reproducibility-support / bundle-prep`

This bundle supports Paper 21 v1.7 of the Interior Observer framework. It
reproduces the live Paper 21 values and theorem-support artifacts that have
public scripts: the `L_1` and `L_2` puncture loads, the AC1/theta_* closure
calculation, the corrected PRyMordial wrapper convention, the corrected BBN
scorecard arithmetic, and the live operator-algebra theorem artifacts.

It is intentionally not a mirror of the private Paper 21 research folder. Dead
route rerunners from the historical `P_resp` investigation are excluded from
the runnable bundle. Their status is preserved in the manuscript and in the
kappa-audit report, but the public scripts focus on currently asserted live
numbers and live theorem-support artifacts.

## Quickstart

```bash
git clone https://github.com/dfife/io-framework-public.git
cd io-framework-public/papers/paper21/v1.7
python3 scripts/07_validate_expected_outputs.py
```

Expected final line:

```text
SUMMARY total_checks=12 pass_count=12 fail_count=0
```

## Full Reproduction

To regenerate every frozen JSON output:

```bash
python3 scripts/01_derive_L1_puncture_load.py
python3 scripts/02_derive_L2_puncture_load.py
python3 scripts/03_compute_ac1_closure.py
python3 scripts/04_prymordial_wrapper_conventions.py
python3 scripts/05_generate_bbn_scorecard.py
python3 scripts/06_operator_algebra_live_theorem_artifacts.py
python3 scripts/07_validate_expected_outputs.py
```

The public rerun path uses only Python standard-library modules. PRyMordial is
not redistributed here; Paper 21's corrected abundance values are frozen from
the private-lab PRyMordial correction audit and this bundle validates the
wrapper convention, denominators, scorecard arithmetic, and theorem-support
calculations.

## Discipline Statement

- `derived`: `L_1` and `L_2` as Paper 21 puncture-load values; AC1/theta_*
  closure inside the reduced scalar/longitudinal acoustic sector.
- `verified`: scorecard arithmetic, YPCMB wrapper convention, frozen-output
  validation.
- `derived/scoped`: optical filtration, T_IO branch assignment, and local
  nontraciality theorem artifacts.
- `historical/superseded`: the old `F_abs / Delta N_eff` response-map hunt and
  the dead `P_resp` route rerunners.

The bundle does not claim that Paper 21 alone derives the Paper 22 rate-dressing
bridge. Paper 21 derives the puncture loads; later rate-dressing use inherits
Paper 22/Paper 25 conditional bridge structure.

## Contents

- `scripts/`: six reproduction scripts plus a validator.
- `data/`: constants, conventions, and frozen PRyMordial support values.
- `results/`: frozen JSON outputs generated by scripts 01-06.
- `reports/`: kappa audit and bundle-scope manifest.
- `environment/`: Python and dependency notes.
