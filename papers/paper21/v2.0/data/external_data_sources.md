# External Data Sources

No external observational dataset is redistributed in this bundle.

The observational denominators used by the scorecard are the IO Framework
standard denominators documented in:

```text
IO Framework Conventions v2.0
https://dfife.github.io/data/conventions_v2.md
```

The underlying PRyMordial solver is an external dependency and is not bundled.
This public bundle validates frozen Paper 21 correction-audit outputs rather
than shipping or reimplementing PRyMordial.

The R4/FIRAS readout normalization is inherited from Paper 17 v1.5. The public
bundle records the resulting value and does not redistribute any external
cosmic microwave background dataset.
