# Paper 21 v2.0 Reproducibility Bundle

Classification: `VERIFIED / public-reproducibility-support`

This bundle supports Paper 21 v2.0, "The AC1 Derivation, the Puncture
Construction, and the Big Bang Nucleosynthesis Branch Assignment." It
reproduces the live Paper 21 numerical claims that have public script support:
the Paper 17 v1.5 R4/FIRAS dependency audit, the `L_1` and `L_2` puncture
loads, the AC1 acoustic closure arithmetic, the corrected PRyMordial wrapper
convention, the corrected Big Bang nucleosynthesis scorecard arithmetic, and
the live operator-algebra theorem artifacts.

This is intentionally not a mirror of the private Paper 21 research folder.
Retired radiation-response route rerunners, the old `F_abs / Delta N_eff`
program, and obsolete appendix-history scans are excluded. The v2.0 paper is
scope-reduced, so the public bundle is also scope-reduced.

## Quickstart

```bash
git clone https://github.com/dfife/io-framework-public.git
cd io-framework-public/papers/paper21/v2.0
python3 scripts/08_validate_expected_outputs.py
```

Expected final line:


## Full Reproduction

To regenerate every frozen JSON output:

```bash
python3 scripts/01_r4_firas_dependency_audit.py
python3 scripts/02_derive_L1_puncture_load.py
python3 scripts/03_derive_L2_puncture_load.py
python3 scripts/04_compute_ac1_closure.py
python3 scripts/05_prymordial_wrapper_conventions.py
python3 scripts/06_generate_bbn_scorecard.py
python3 scripts/07_operator_algebra_live_theorem_artifacts.py
python3 scripts/08_validate_expected_outputs.py
```

The public rerun path uses only Python standard-library modules. PRyMordial is
not redistributed here; Paper 21's corrected abundance values are frozen from
the private-lab correction audit, and this bundle validates the wrapper
convention, observational denominators, scorecard arithmetic, and
theorem-support calculations.

## Discipline Statement

- `DERIVED/THEOREM`: `L_1` and `L_2` as Paper 21 puncture-load values, the
  fixed-point algebra, conformal transparency, and algebraic theorem artifacts.
- `DERIVED/CONDITIONAL_VERIFIED`: AC1 closure and the Big Bang
  nucleosynthesis branch assignment where the theorem statement relies on a
  declared, traceable premise package or reduced observable class.
- `VERIFIED`: scorecard arithmetic, YPCMB wrapper convention, R4 dependency
  audit, and frozen-output validation.
- `IMPORTED/EMPIRICAL`: `R4_FIRAS`, inherited from Paper 17 v1.5's
  FIRAS-fixed unique optical readout normalization.
- `SUPERSEDED`: the old `F_abs / Delta N_eff` response-map hunt, the dead
  `P_resp` route rerunners, and independent cosmic microwave background
  temperature prediction wording.

The bundle does not claim that Paper 21 alone derives the Paper 22
rate-dressing bridge. Paper 21 derives the puncture loads; later delivery into
the weak and nuclear rate-dressing channels is Paper 22/Paper 25 structure.

## Contents
