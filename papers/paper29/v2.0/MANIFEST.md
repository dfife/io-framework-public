# Manifest

## Root Files

- `README.md` - bundle overview, quickstart, and claim boundaries.
- `MANIFEST.md` - file inventory.
- `VERSION.md` - version metadata and constants snapshot.
- `CITATION.cff` - citation metadata.
- `LICENSE` - MIT license for bundle code and documentation.
- `CONSTRUCTION_SUMMARY.md` - script-by-script construction summary.
- `INVENTORY_REPORT.md` - manuscript/bundle reconciliation notes.
- `SHA256SUMS.txt` - SHA256 checksums for bundle files.

- `data/external_data_sources.md`

`data/.cache/` are ignored and should be regenerated by the scripts.
