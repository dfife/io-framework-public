# Paper 32 Public Reproducibility Bundles

This directory contains public reproducibility bundles for Paper 32 of the
Interior Observer framework.

Current bundle:

- `v1.6/` - Paper 32 v1.6 reproducibility bundle, including the Paper 17
  R4/FIRAS repair, framework constants, recollapse/cycle calculations,
  source-block KB.7 validation, scalar-index and scalar-amplitude arithmetic,
  GMP classification, and the R4 damage kappa audit.

Previous bundle:

- `v1.5/` - Paper 32 v1.5 reproducibility bundle, including framework
  constants, recollapse/cycle calculations, source-block KB.7 validation,
  scalar-index and scalar-amplitude arithmetic, GMP classification, and the
