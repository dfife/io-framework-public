# External Dependencies

The quick validator requires only Python 3.

Optional heavy reruns require:

- CAMB
- CLASS/classy
- scipy
- numpy
- sympy
- mpmath
- PRyMordial for the BBN rerun
- Public BOSS DR12 full-shape archive
- DESI BAO mean and covariance files for scorecard/BAO reruns

External data and PRyMordial are not redistributed. See
`data/external_data_sources.md`.
