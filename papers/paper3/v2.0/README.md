# Paper 3 v2.0 Reproducibility Bundle

This bundle supports Paper 3 v2.0 of the Interior Observer framework. It
reproduces the active-branch constants, the Paper 3 transfer-function table,
the radicand-positivity and monotonicity theorem checks, and the sharp
equation-of-state junction-limit arithmetic.

Paper 3 v2.0 is an input-structure paper. It does not perform observational
confrontation. The observed CMB temperature is treated under the Paper 17 v1.5
FIRAS-fixed observer-side readout normalization and is not counted here as an
independent IO temperature prediction.

## Quickstart

```bash
git clone https://github.com/dfife/io-framework-public.git
cd io-framework-public/papers/paper3/v2.0
python3 scripts/05_validate_expected_outputs.py
```

Expected final line:

```text
SUMMARY total_checks=24 pass_count=24 fail_count=0
```

## Detailed Reproduction

To regenerate the frozen JSON outputs:

```bash
python3 scripts/01_active_branch_constants.py
python3 scripts/02_transfer_table.py
python3 scripts/03_radicand_positivity_and_monotonicity.py
python3 scripts/04_sharp_eos_junction_limit.py
python3 scripts/05_validate_expected_outputs.py
```

## Discipline Statement

This bundle separates Paper 3 arithmetic and theorem-surface checks from
upstream derivations:

- Reproduced in scripts: `r_s`, `R_U`, the thermal invariant, `a0`, the active
  transfer table, the active-branch `Q(y)>0` inequality, the `dQ/dy>0`
  monotonicity inequality, and the sharp-EOS acceleration ratio.
- Cited, not rederived: the P1 container, the Paper 10 / Paper 29 active
  projection branch, Paper 5's continuous mixed-fluid interior, Paper 17's
  FIRAS readout normalization, and Paper 30's master-clock placement.
- Rehomed, not claimed as Paper 3 confrontation: active-branch `z_eq`.

## Contents

- `scripts/`: five public reproduction/validation scripts.
- `data/`: constants, formulas, claim boundaries, and source pointers.
- `results/`: frozen JSON outputs generated by scripts 01-04.
- `reports/`: theorem memos for the continuity/monotonicity pair and the
  sharp-EOS junction limit.
- `environment/`: Python version, requirements, external dependency notes, and
  randomness/seed statement.
