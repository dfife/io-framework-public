# External Dependencies

The Paper 3 v2.0 public bundle uses only the Python standard library for its
scripts. It imports no external Python packages.

Scientific dependencies are cited in the manuscript and reports, not installed
by this bundle:

- Oppenheimer-Snyder closed dust interior under the P1/P2 container.
- Israel-Darmois matching conditions.
- Standard FRW and Raychaudhuri equations.
- Paper 10 / Paper 29 active-branch constants.
- Paper 17 v1.5 FIRAS readout-normalization boundary.
- Paper 30 active master-clock placement.
