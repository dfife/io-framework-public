## Core No-Go

Let α_t^(κ) = Ad(exp(i t κ D)) be the fiber modular flow derived in Paper 17. Any continuous identification between modular time t and conformal depth λ has the form t = c λ. Therefore the physical transfer law without R4 is d(ln ω)/dλ = c κ; on the physical sector κ = K_gauge, so σ = c K_gauge.

Proof skeleton:
- Let φ: (R,+) -> (R,+) be continuous and additive.
- Additivity gives φ(n λ) = n φ(λ) for all integers n and φ(q λ) = q φ(λ) for all rationals q.
- Set c = φ(1). Then φ(q) = c q for all rationals q.
- By continuity, φ(λ) = c λ for all real λ.
- Hence the only continuous reparameterizations of an additive flow are constant rescalings.

This kills the claim that the canonical normalization of modular time and the canonical normalization of λ automatically force `c = 1`. They fix two separate additive parameters, not the bridge between them.

## Why The Earlier March Closures Fail

### 1. The conformal-cell theorem

The March claim was: λ counts conformal e-fold cells, therefore one unit of λ carries one factor `s = 1 + γ²`. But if the physical transfer cell has width `δ` in λ, exactly the same argument gives

```text
U(λ) = s^(λ/δ) = exp((ln s / δ) λ)
σ = (1/δ) ln s = (1/δ) K_gauge
```

So the old proof assumes `δ = 1`. That is R4 itself in disguised form.

### 2. The Gaussian S² normalization corollary

The Gaussian determinant ratio proves `K_gauge = ln(1 + γ²)`. It does not prove the coefficient in `σ = c K_gauge`. The old corollary silently identified normalization of the gauge scalar with normalization of the geometric readout map. Those are different objects.
