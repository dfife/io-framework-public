Paper 17
Foundation Closure Attempt
Closing the Three High Gaps Under the Modular Projection Theorem

Question

    Close the three upstream gaps under the modular projection theorem:

    1. construct the actual state omega_A on the thermal-plus-gauge algebra;
    2. derive the reduction to M_th bar-tensor Z_g from that state;
    3. prove fiberwise KMS inheritance from the constructed state.


Executive result

    The three gaps can be closed inside the reduced Schwarzschild tangential IO class.

    The key move is to stop treating the A-vacuum as an undefined vector and instead construct it
    as a gauge-invariant direct-integral KMS state on the reduced thermal-plus-gauge von Neumann
    algebra.

    The closure is explicit:

    - gap 1 closes by an explicit state formula;
    - gap 2 closes by compact-group averaging plus Schur reduction;
    - gap 3 closes because the state is fiberwise KMS by construction, so the direct-integral GNS
      decomposition carries the KMS property fiberwise.

    Strongest honest status:

        DERIVED / THEOREM inside the reduced Schwarzschild tangential thermal sector.

    Exact scope:

        the reduced IO sector already used in Papers 14-17, not the full unreduced horizon algebra.


==================================================
I. Algebraic setting
==================================================

I.1 Thermal photon algebra
    Let M_th be the thermal photon von Neumann algebra used in Papers 13 and 17. Its exact
    Planck-preserving transfer dynamics on the conformal frequency variable

        nu = ln omega

    is generated by the dilation operator D.

I.2 Reduced gauge bundle
    Let Sigma = spec(K_hat_g). Write the reduced gauge Hilbert space as a direct integral

        H_g = integral direct sum H_kappa d mu_A(kappa),

    where on each fiber H_kappa:

    - the reduced tangential gauge action is irreducible,
    - K_hat_g acts as

          K_hat_g |_(H_kappa) = kappa I_(H_kappa).

    In the physical Schwarzschild specialization of Papers 14-16, Sigma collapses to the single
    value

        kappa = K_gauge = ln(1 + gamma^2),

    but keeping the direct integral makes the reduction and fiber statements transparent.

I.3 Big algebra
    Define

        M_big := integral direct sum (M_th bar-tensor B(H_kappa)) d mu_A(kappa).

    This is the reduced thermal-plus-gauge algebra before quotienting to the gauge-invariant
    thermal sector.


==================================================
II. The actual A-vacuum state
==================================================

II.1 Fiber photon states
    For each kappa in Sigma, let phi_kappa be the faithful normal KMS state on M_th for the
    one-parameter dynamics

        alpha_t^(kappa) = Ad(exp(it kappa D)).

    This is exactly the thermal photon state associated with the fiber transfer generator kappa D.
    The existence of such faithful normal KMS states is standard in the operator-algebraic thermal
    framework used already in Paper 13.

II.2 Fiber gauge state
    On each finite-dimensional reduced tangential fiber B(H_kappa), let tau_kappa be the normalized
    trace. It is faithful, normal, and invariant under the reduced SU(2) gauge action.

II.3 State definition
    For decomposable X in M_big, define

        omega_A(X)
        := integral phi_kappa( (id bar-tensor tau_kappa)(X(kappa)) ) d mu_A(kappa).

    Equivalently:

        omega_A
        = integral (phi_kappa bar-tensor tau_kappa) d mu_A(kappa).


==================================================
III. Gap 1 closure — positivity, normalization, faithfulness, GNS
==================================================

Theorem 17.25 (explicit A-vacuum state theorem)
    The functional omega_A on M_big is a positive normalized faithful normal state. Therefore it
    admits a GNS representation

        (pi_A, H_A, Omega_A).

Proof
    Positivity:
        if X >= 0, then X(kappa) >= 0 for almost every kappa, the slice map

            id bar-tensor tau_kappa

        is positive, each phi_kappa is positive, and the integral of nonnegative numbers is
        nonnegative.

    Normalization:
        for the unit,

            omega_A(1)
            = integral phi_kappa(1) tau_kappa(1) d mu_A(kappa)
            = integral 1 d mu_A(kappa)
            = 1,

        after choosing mu_A as a probability measure on Sigma.

    Faithfulness:
        let X >= 0 and omega_A(X) = 0. Then

            phi_kappa( (id bar-tensor tau_kappa)(X(kappa)) ) = 0

        for almost every kappa. Since phi_kappa is faithful,

            (id bar-tensor tau_kappa)(X(kappa)) = 0.

        Since tau_kappa is faithful on B(H_kappa),

            X(kappa) = 0

        for almost every kappa. Hence X = 0.

    Normality:
        each fiber state is normal and the direct integral preserves normality.

    GNS then follows from the standard GNS theorem for states on C*- / von Neumann algebras.

Conclusion
    Gap 1 is closed mathematically.


==================================================
IV. Gap 2 closure — reduction to M_th bar-tensor Z_g
==================================================

IV.1 Compact-group conditional expectation
    Let beta_u be the reduced SU(2) gauge action on M_big:

        beta_u(X)(kappa)
        := (I bar-tensor Ad(U_kappa(u)))(X(kappa)).

    Since SU(2) is compact, Haar averaging defines a faithful normal conditional expectation

        E_g(X)
        := integral beta_u(X) d u

    onto the fixed-point algebra M_big^(SU(2)).

IV.2 Schur reduction on each fiber
    Because H_kappa is irreducible for the reduced tangential gauge action, Schur's lemma implies
    that the fixed-point algebra of B(H_kappa) is exactly the scalars:

        B(H_kappa)^(SU(2)) = C I_(H_kappa).

    Therefore

        M_big^(SU(2))
        = integral direct sum (M_th bar-tensor C I_(H_kappa)) d mu_A(kappa)
        = M_th bar-tensor Z_g,

    where

        Z_g = W*(K_hat_g)

    is the abelian von Neumann algebra of decomposable scalar fiber operators.

IV.3 State invariance
    Because tau_kappa is gauge-invariant,

        omega_A o beta_u = omega_A

    for every u in SU(2). Hence

        omega_A = omega_A o E_g.

Theorem 17.26 (state-derived reduction theorem)
    For every thermal photon observable A in M_th and every gauge operator B in the reduced gauge
    algebra,

        omega_A(A bar-tensor B)
        = omega_A(A bar-tensor E_g(B)).

    Therefore all thermal photon correlators depend only on the central reduced gauge algebra

        Z_g,

    and the relevant thermal photon sector is legitimately reduced to

        M_th bar-tensor Z_g.

Proof
    Since A bar-tensor I commutes with the gauge averaging,

        E_g(A bar-tensor B) = A bar-tensor E_g(B),

    and because omega_A = omega_A o E_g,

        omega_A(A bar-tensor B)
        = omega_A(E_g(A bar-tensor B))
        = omega_A(A bar-tensor E_g(B)).

    By Schur reduction, E_g(B) is fiberwise scalar, hence belongs to Z_g.

Conclusion
    Gap 2 is closed inside the reduced tangential thermal sector.

V. Gap 3 closure — fiberwise KMS inheritance
==================================================

V.1 Restricted state on the reduced sector
    On

        N := M_th bar-tensor Z_g

    the state reduces to the decomposable form

        omega_A |_N
        = integral phi_kappa d mu_A(kappa),

    because the gauge factor has already been collapsed to scalar fiber labels.

V.2 Fiber dynamics
    Let

        alpha_t = integral direct sum alpha_t^(kappa) d mu_A(kappa),
        alpha_t^(kappa) = Ad(exp(it kappa D)).

Theorem 17.27 (fiberwise KMS inheritance theorem)
    The global state omega_A |_N is KMS for alpha_t, and in the direct-integral GNS decomposition
    its fiber vectors Omega_kappa are KMS for the fiber dynamics alpha_t^(kappa).

Proof
    The state is built fiberwise from the faithful normal KMS states phi_kappa. Therefore for every
    decomposable pair X, Y in N, the KMS boundary-value relation holds fiberwise almost
    everywhere:

        F_kappa(t+i)
        = phi_kappa( alpha_t^(kappa)(Y) X ).

    Integrating over kappa gives the global KMS strip function for omega_A |_N.

    In the GNS representation of a direct-integral state, the GNS Hilbert space decomposes as the
    direct integral of the fiber GNS spaces, and the cyclic vector decomposes as

        Omega_A = integral direct sum Omega_kappa d mu_A(kappa).

    Since each Omega_kappa is by construction the GNS vector of phi_kappa, each fiber vector is
    KMS for alpha_t^(kappa).

Conclusion
    Gap 3 is closed by construction rather than by an extra inheritance axiom.
