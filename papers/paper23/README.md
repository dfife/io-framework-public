# Paper 23 Public Bundles

This directory contains public reproducibility bundles for Paper 23 of the
Interior Observer framework.

## Available Bundles

- `v2.0/` - R4/FIRAS repair audit, closed-S3 perturbation bookkeeping, bridge
  operator support, No-Doubling/spectral-index evaluation, and tensor-sector
  scope ledger.

Each published bundle is also archived as an immutable GitHub release tag using
the repository convention `paper23-vX.Y`.
