I. Lemma 23.A - quasi-free restriction
--------------------------------------

The current Paper 17 scope is the reduced thermal photon sector. Paper 22 already
records the exact boundary:

    the Ashtekar-Barbero connection is not presently realized as an operator
    inside the bare photon algebra M_th.

So the bridge algebra is not a literal subalgebra of bare M_th.

The natural Hilbert-space repair is the minimal spatial one-particle lift

    h_vec = L^2(R,dnu) tensor H_g tensor Omega^1_coex(S^3),
    H_vec = Gamma_s(h_vec).

For each scalar shell mode Q_(N,M), define the bridge functional

    L_(N,M)(delta A)
    = <Q_(N,M), B_N delta A>
    = int_(S^3) overline(Q_(N,M)) g^(ab) kappa_ij Abar_a^i delta A_b^j dmu.

Because S^3 is compact and the coefficients are smooth, L_(N,M) is bounded on the
vector one-particle Hilbert space. Hence by Riesz there exists a unique

    F_(N,M) in h_vec

with

    L_(N,M)(delta A) = <F_(N,M), delta A>_(h_vec).

Define the real bridge test space

    h_br = closure_R span { F_(N,M) }.

Then the bridge algebra is the Weyl CCR subalgebra

    W_br = CCR(h_br, sigma|_(h_br)) subset CCR(h_vec, sigma).

If the ambient lifted A-vacuum is quasi-free, i.e.

    omega_vec(W(f)) = exp[-mu_vec(f,f)/4],

then on h_br we simply restrict the quadratic form:

    mu_br = mu_vec|_(h_br),
    omega_vec|_(W_br)(W(f)) = exp[-mu_br(f,f)/4].

So the restriction is again quasi-free.

In creation-annihilation form the bridge covariance is

    C_(N,M;N',M')
    = omega_vec(a^*(F_(N,M)) a(F_(N',M')))
    = <F_(N',M'), G^(1) F_(N,M)>,

where G^(1) is the one-particle covariance operator of the lifted state.

This is the load-bearing point:

    the bridge two-point function is one covariance kernel on one-particle space,
    not two independently dressed bridge legs.


II. Lemma 23.B - zero-order bridge preserves alpha = 1
------------------------------------------------------

Write the bridge as

    B_N = Pi_N^(0) S_Abar,
    S_Abar(delta A) = g^(ab) kappa_ij Abar_a^i delta A_b^j.

The active perturbation delta A is processed by:

1. pointwise metric contraction g^(ab),
2. pointwise internal trace kappa_ij,
3. multiplication by the fixed background Abar,
4. orthogonal harmonic projection Pi_N^(0).

Each of these is zero-order in the active field:

    ord(S_Abar) = 0,
    ord(Pi_N^(0)) = -infinity

because Pi_N^(0) is finite-rank / smoothing.

Paper 19 already identified the only theorem-grade rung-changing mechanisms:

    alpha = 3/2  from free-fall / timelike continuity scalarization,
    alpha = 2    from intrinsic slice codifferential scalarization.

Both require differentiation of the active one-form or insertion of a new
Jacobian factor. The bridge does neither.

Therefore if O^(1) is on the primitive one-form rung,

    alpha(O^(1)) = 1,

then

    alpha(B_N O^(1)) = alpha(O^(1)) = 1.

So the bridge preserves the alpha = 1 rung.

Theorem 23.S (conditional spectral index theorem on the bridge CCR sector)
---------------------------------------------------------------------------

On the minimal spatial CCR lift of the Paper 17/22 Hilbert package, the
one-particle bridge covariance is the primitive state datum by Lemma 23.A. By
Lemma 23.B together with Papers 12, 18, and 19, that covariance remains on the
state-level reduced-center one-form rung.

If, in addition, a generator-level projection theorem acts on that covariance so
that

    G^(1) = sum_(n>=1,sigma) g_n^(sigma) Pi_n^(sigma),
    g_n^(sigma) = g_* [k_MS(n)/k_*]^(-K_gauge/x),
    k_MS(n)^2 = (n-1)(n+3) / R_curv^2.

Then the scalar bridge covariance is

    C^(0) = B G^(1) B^dagger,

with exact shell form

    C_N
    = beta_(N,-)^(+) g_(N-1)^(+)
    + beta_(N,-)^(-) g_(N-1)^(-)
    + beta_(N,+)^(+) g_(N+1)^(+)
    + beta_(N,+)^(-) g_(N+1)^(-).

In the parity-symmetric case this reduces to

    C_N = B_(N,-) g_(N-1) + B_(N,+) g_(N+1).

Therefore the effective scalar-shell tilt is

    1 - n_s^(eff)(N)
    = (K_gauge/x) * N(N+1)/[(N-1)(N+3)] - d ln A_N / d ln N,

    A_N = B_(N,-) exp[-(K_gauge/x) Delta_(N,-)]
        + B_(N,+) exp[-(K_gauge/x) Delta_(N,+)],

    Delta_(N,pm) = ln[k_MS(N pm 1)/k_MS(N)].

Hence the leading spectral exponent is

    K_gauge / x = 0.036124303978219,

not

    2 K_gauge / x.

If the bridge branch norms are shell-flat at leading order, this reduces to the
closed-universe shell law

    1 - n_s(N)
    = (K_gauge/x) * N(N+1)/[(N-1)(N+3)]

up to lower-order adjacency corrections.
