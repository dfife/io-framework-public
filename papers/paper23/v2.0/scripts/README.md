# Paper 23 v2.0 Scripts

Run the full bundle validator:

```bash
python3 papers/paper23/v2.0/scripts/08_validate_expected_outputs.py
```

Each numbered script is standalone and writes one JSON file to
`papers/paper23/v2.0/results/`.

The scripts use only the Python standard library. They intentionally reproduce
the live theorem-support numbers and do not rerun every historical exploratory
route from the private lab.
