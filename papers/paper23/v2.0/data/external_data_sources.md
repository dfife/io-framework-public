# External Data and Reference Sources

This bundle does not redistribute external observational datasets.

## References Used as Numeric Comparators

- FIRAS CMB temperature:
  - Used only through the Paper 17 v1.5 imported empirical readout convention.
  - The bundle freezes `T_FIRAS = 2.7255 K` for the R4 audit.
  - No FIRAS data products are redistributed.

- Planck scalar spectral index:
  - Used as the manuscript comparison value `1 - n_s = 0.0351 +/- 0.0042`.
  - The bundle records the comparison value but does not redistribute Planck likelihoods.

## Licensing Rule

If a future script requires an external dataset, fetch it from the publisher or
collaboration source and record its checksum. Do not redistribute external
datasets in this repository unless their license explicitly allows it.
