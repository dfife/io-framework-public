# Paper 25 Reproducibility Bundles

Paper 25: *The Weak-Sector Identity Pin / Quadratic Thermal Covariance, the
Channel-Budget Equation, and the V-vs-V' Class-Membership Theorem*.

Available bundles:

- `v1.3/`: support package for Paper 25 v1.3.
- `v2.0/`: current support package for Paper 25 v2.0, aligned to the Paper 24
  v3.0 Pastore `Q_GS` BBN branch and the Paper 17 v1.5 R4/FIRAS boundary.

Use the version matching the manuscript being read. Each version directory is
immutable after release; future corrections should create a new sibling version
directory.
