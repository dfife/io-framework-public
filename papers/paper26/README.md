# Paper 26 Reproducibility Bundles

Paper 26: *The Primordial Scalar Amplitude from the Hawking Boundary State,
IO-Native Replacements for LambdaCDM-Borrowed Inputs, the CMB Baryon Class
Diagnostic, and the Effective Optical Damping Parameter*.

Available bundles:

- `v1.2/`: current support package for Paper 26 v1.2.

Use the version matching the manuscript being read. Each version directory is
immutable after release; future corrections should create a new sibling version
directory.
