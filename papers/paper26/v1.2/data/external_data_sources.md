# External Data Sources

The Paper 26 v1.2 public validation path uses frozen audited outputs and
Python standard-library arithmetic. It does not redistribute Planck likelihoods,
CLASS, or external observational datasets.

External sources cited by the manuscript and support reports include:

- Planck 2018 cosmological parameters for the reference scalar amplitude and
  optical-depth context.
- Hawking 1975 for the horizon-temperature state.
- CLASS for the CMB thermodynamics and perturbation diagnostics.
- Standard cosmological perturbation theory for the dust superhorizon
  conversion factor.

The public scripts verify arithmetic and frozen audited rows. They are not a
replacement for a full CLASS or Planck-likelihood environment.
