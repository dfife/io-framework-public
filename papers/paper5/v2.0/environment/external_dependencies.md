# External Dependencies

This bundle has no runtime external package dependency. It uses only Python
standard-library modules.

The scientific inputs are imported constants and already-published cross-paper
results from Papers 1, 10, 12, 20, 22, 24, 29, 30, and 34. Those papers remain
the source of their own theorem claims. This bundle only reproduces the Paper 5
v2.0 support arithmetic and the local no-go diagnostic used in the rebuilt
manuscript.
