# Paper 34 v2.0 Reproducibility Bundle

Classification: `verified / public-reproducibility-support / R4-FIRAS audited`

This bundle contains the curated scripts, frozen outputs, constants, and audit
reports needed to reproduce the Paper 34 v2.0 Hubble-tension scorecard,
anti-fit checks, and R4/FIRAS non-dependency audit.

It is intentionally not a mirror of the private research lab. Exploratory route
searches, killed-route scans, private scratch state, and manuscript drafts are
excluded.

## Contents

- `scripts/01_compute_hext_grid.py`
  - Computes the full `(alpha,n)` grid for the Paper 34 `H_ext` formula.
- `scripts/02_compare_to_published_measurements.py`
  - Computes six-method H0 pulls against imported published comparison values.
- `scripts/03_run_anti_fit_check.py`
  - Reproduces the anti-fit backstop table.
- `scripts/04_r4_firas_impact_audit.py`
  - Audits the Paper 17 v1.5 R4/FIRAS repair against Paper 34 and verifies
    that the Hubble scorecard has no active R4 dependency.
- `scripts/05_validate_expected_outputs.py`
  - Fast validation of the frozen result files included in this bundle.
- `data/imported_constants.json`
  - Framework constants and published H0 comparison values.
- `results/`
  - Frozen JSON outputs generated by the scripts.
- `reports/`
  - Kappa-style structural audit report and JSON.
  - v2.0 Planck compound-CMB classification memo.
  - v2.0 §10 scoped-closure memo for the baseline branch, inverse-projector placement, stellar-photometric extension, and centered lens-normalization extension.

## Claim Boundary

- `verified`: arithmetic grid generation, scorecard pull calculation, frozen
  output validation, anti-fit table reproduction, and R4/FIRAS impact audit.
- `derived/scoped`: Paper 34's v2.0 scoped closure package as stated in the
  manuscript, Planck classification memo, §10 scoped-closure memo, and
  kappa-audit report.
- `not claimed`: Paper 34 does not independently predict the observed CMB
  temperature. The `Planck CMB` row is a compound CMB-inference / baseline projected-background row, and these
  scripts do not prove the extension premises by themselves.
- `not included`: private route-search scripts, failed route scans, draft
  manuscripts, and non-public scratch state.
