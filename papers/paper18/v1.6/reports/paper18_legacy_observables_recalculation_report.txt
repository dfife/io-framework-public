Paper 18
Legacy Observable Recalculation on the Active Schur Branch

Question

    Recompute four legacy observables using the definitive Paper 18 branch

        H_0 = 68.91 km/s/Mpc,
        P_k = exp(-Delta/2),
        N_eff = Delta,
        f_b = 2 gamma / x = 0.3127,
        T_obs = 2.7253 K,

    and compare honestly to observation.


Executive result

    The active Schur branch does not move all legacy observables in the same direction.

    1. BAO stays essentially unchanged:

           chi^2_DESI_DR1 = 19.80

       on the 12-point DESI DR1 GCcomb dataset, matching the Paper 12 scorecard.

    2. sigma_8 changes materially:

           sigma_8 = 0.7593,
           S_8     = 0.8023

       in the same borrowed-primordial setup used by Paper 6 / Paper 4.
       The old Paper 4 value

           sigma_8 = 0.578

       belongs to the superseded pre-projection geometric branch and is no longer active.

    3. The true dark-energy equation of state stays

           w = -1

       exactly. But the old curvature-induced flat-CPL mimic nearly disappears:

           w_0,apparent = -1.0060

       instead of the legacy geometric-branch

           w_0,apparent = -1.108.

    4. The MOND scale is unchanged:

           a_0 = c^2 / r_s = 1.3444 x 10^-10 m/s^2,

       still about 12.0% above the canonical empirical

           a_0 ~ 1.2 x 10^-10 m/s^2.

II. BAO chi^2 against DESI DR1
==================================================

Method

Use the standard FRW distance relations with the active Paper 18 background:

    H(z)^2 = H_0^2 [ Omega_r (1+z)^4
                   + Omega_m (1+z)^3
                   + Omega_k (1+z)^2
                   + Omega_Lambda ].

For BAO, evaluate

    D_M(z) / r_d,
    D_H(z) / r_d,
    D_V(z) / r_d

against the official DESI DR1 12-point GCcomb Gaussian likelihood

    desi_2024_gaussian_bao_ALL_GCcomb_mean.txt
    desi_2024_gaussian_bao_ALL_GCcomb_cov.txt

using the Paper 12 geometric ruler

    r_d,IO = 143.3 Mpc.

Result

    chi^2_IO(DESI DR1) = 19.8016
    PTE               = 0.0709

For a flat Planck-like LambdaCDM reference with

    H_0 = 67.36,
    Omega_m = 0.3153,
    Omega_k = 0,
    T_0 = 2.7255 K,
    N_eff = 3.046,
    r_d = 147.09 Mpc,

the same likelihood gives

    chi^2_LambdaCDM-like = 21.1232
    PTE                  = 0.0486.

Interpretation

    BAO does not materially change under the Paper 18 curvature resolution.
    The active Schur branch reproduces the old Paper 12 result:

        chi^2 = 19.8

    almost exactly.

What changed:

    nothing important in the BAO sector between late Paper 12 and active Paper 18.

What did not change:

    BAO remains a moderate success for IO on the projected branch.


==================================================
III. sigma_8 and S_8
==================================================

Method

As in Paper 6, use CLASS with the IO background but borrow the primordial parameters from
LambdaCDM because the IO framework still has not derived them:

    A_s = 2.1 x 10^-9
    n_s = 0.9649
    tau_reio = 0.0544

and take a minimal neutrino sector

    sum m_nu = 0.06 eV.

This means the recalculated sigma_8 is not a new theorem of IO primordial physics.
It is the active-branch value in the same "borrowed primordial sector" convention already used
in Paper 6 / Paper 4.

Active Schur-branch result

Using

    H_0 = 68.91
    Omega_m = 0.335
    Omega_k = -0.006
    T_0 = 2.7253 K
    N_eff = Delta
    omega_b,geom = 0.02108

gives

    sigma_8 = 0.7593
    S_8     = sigma_8 sqrt(Omega_m/0.3) = 0.8023.

Sensitivity check

If one incorrectly feeds the acoustic baryon loading into the late-time growth calculation,

    omega_b,eff = 0.02910,

then one gets

    sigma_8 = 0.6930
    S_8     = 0.7323.

That is not the active structure-growth choice; it is listed only to show sector sensitivity.

Comparison to observations

Planck 2018:

    sigma_8 = 0.8111 +- 0.0060
    S_8     = 0.832 +- 0.013

KiDS-Legacy 2025:

    S_8 = 0.815^(+0.016)_(-0.021)

DES Y3 official 3x2pt:

    S_8 = 0.776 +- 0.017

Numerically:

    relative to Planck sigma_8:
        0.7593 vs 0.8111  -> lower by 0.0518

    relative to Planck S_8:
        0.8023 vs 0.832   -> lower by 0.0297

    relative to KiDS-Legacy S_8:
        0.8023 vs 0.815   -> lower by 0.0127

    relative to DES Y3 S_8:
        0.8023 vs 0.776   -> higher by 0.0263

Interpretation

    The active Schur branch removes the old Paper 4 "very low sigma_8" signature.
    IO is still below Planck, but it is no longer the extreme low-growth model with

        sigma_8 = 0.578.

    On S_8, the active branch lands between KiDS-Legacy and DES:

        - slightly below KiDS-Legacy,
        - slightly above DES Y3,
        - below Planck.

So the honest update is:

    the active branch weakens the old Paper 4 claim that IO naturally resolves the S_8 tension.

IV. Dark-energy equation of state
==================================================

True IO equation of state

Paper 4's exact statement survives unchanged:

    rho_Lambda is a spatial calibration at the observer position,
    not a dynamical fluid evolution,

so

    w = -1

still holds exactly on the active branch.

What does change is the apparent flat-CPL misread generated by closed curvature.

Using the Paper 4 formula with the active branch

    Omega_k = -0.006,
    Omega_Lambda = 0.6708814474,

gives

    w_0,apparent = -1 + (2/3) Omega_k / (Omega_k + Omega_Lambda)
                  = -1.00601611.

Comparison to the legacy geometric branch:

    old Paper 4 geometric branch: w_0,apparent = -1.108
    active Schur branch:          w_0,apparent = -1.006

Interpretation

    The curvature resolution does not change the exact IO statement

        w = -1.

    But it does almost completely erase the earlier phantom-looking curvature mimic.

Current observational context

    Constant-w fits remain broadly consistent with w = -1, while newer DESI combined analyses
    increasingly explore w(z) evolution rather than a single constant-w parameter.

So the honest Paper 18 update is:

    - exact IO w = -1 survives unchanged,
    - the old dramatic apparent-phantom offset no longer survives on the active branch.
