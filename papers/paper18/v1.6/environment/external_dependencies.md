# External Dependencies

The default validator reruns the core theorem scripts and validates the frozen external-data outputs.

Optional full external reruns require:

- CLASS with Python `classy` module, locally observed as version `v3.3.4`.
- CAMB Python package, locally observed as version `1.6.6`.
- DESI DR1 Gaussian BAO mean/covariance files.
- Beutler et al. BOSS DR12 full-shape public archive, fetched by script 10.

No external observational dataset is redistributed in this repository.
