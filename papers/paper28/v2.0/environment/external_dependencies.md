# External Dependencies

There are no runtime external data dependencies.

The mathematical dependencies are literature dependencies cited in the Paper
28 v2.0 manuscript and support reports:

- Compact coexact one-form spectral theory.
- Dirichlet-to-Neumann boundary Hessian theory.
- Oppenheimer-Snyder closed-interior geometry.
- Standard radial null redshift in closed Friedmann-Robertson-Walker form.

These are cited as standard physics/mathematics inputs, not shipped as data.
