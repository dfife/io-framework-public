# External Data Sources

Paper 28 v2.0 does not redistribute external observational datasets.

The bundle uses closed-form formulas and theorem-support arithmetic for the
spectral-index chain and the homogeneous Oppenheimer-Snyder JWST
formation-clock map. Literature inputs are standard mathematical/physics
theorems cited by the manuscript and support reports:

- Hodge theory and coexact one-form spectral theory on compact manifolds.
- Differential-form Dirichlet-to-Neumann operators on the `B^3/S^2` collar.
- Standard Oppenheimer-Snyder interior geometry and radial null redshift
  relation.
- `R4_FIRAS = 1.0031014644`, imported from Paper 17 v1.5. Paper 28 v2.0 does
  not use R4 to claim an independent CMB-temperature prediction.

No Planck likelihoods, FIRAS data files, JWST data products, or CLASS output
tables are bundled.
