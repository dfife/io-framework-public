# External Dependencies

The public validation scripts require no external runtime dependencies beyond
Python 3.

PRyMordial is not redistributed. The corrected PRyMordial output row is frozen
as data with provenance to the private correction audit.

The FIRAS temperature is not redistributed as a dataset. The scalar imported
value used by Paper 17 v1.5 to fix `R4_FIRAS` is recorded in
`data/imported_constants.json`.
